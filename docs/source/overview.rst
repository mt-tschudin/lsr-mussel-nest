Overview
========

The LSR Mussel Nest is a modular underwater research platform developed to
study and interact with quagga mussel colonization on submerged scientific
infrastructure.

The project was motivated by recurring biofouling at the LéXPLORE research
platform on Lake Geneva, where quagga mussels can densely colonize sensors,
mooring structures, and other submerged equipment. The system is intended to
support future experiments that combine repeatable visual monitoring with
localized physical stimulation.

System Concept
--------------

The platform combines four experimental cages with a central underwater
electronics pod.

The four cages consist of:

* one UVC-treated test surface
* one propeller-treated test surface
* two untreated control surfaces

Each cage is monitored by a dedicated camera. The treated and control surfaces
can therefore be compared under similar environmental conditions.


System Architecture
-------------------

The system is distributed across a surface Brain Pi, an underwater Pod Pi,
and four ESP32-S3 camera modules.

::

    Operator
       │
       │ Wi-Fi / SSH
       ▼
    Brain Pi
       │
       │ Ethernet
       ▼
    Pod Pi
       │
       ├── 4 × cameras
       ├── 2 × UVC lamps
       └── 2 × propellers

The Brain Pi handles high-level commands, experiment execution, and data
storage. The Pod Pi provides the local hardware interface and controls the
cameras and actuators.


Monitoring and Stimulation
--------------------------

Monitoring is performed through scheduled image capture. Each camera uses an
integrated LED ring to provide controlled illumination, and captured images are
transferred through the Pod Pi to the Brain Pi.

Two localized stimulation methods are integrated:

* **UVC irradiation** — switched through electrical relays
* **Hydrodynamic stimulation** — generated by propellers controlled through ESCs

The current system operates in open loop: monitoring and stimulation are
controlled independently. A future extension could use detected colonization
as feedback to trigger stimulation automatically.

Project Status
--------------

The prototype provides the main engineering functions required for field
experiments, including remote communication, automated image acquisition,
UVC switching, and propeller control.

The next stage is long-term deployment at LéXPLORE to evaluate system
reliability and compare biological colonization between treated and untreated
surfaces.
