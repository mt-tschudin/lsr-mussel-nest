LSR Mussel Nest Documentation
=============================

Welcome to the documentation for the LSR Mussel Nest project.

This documentation describes the system architecture, hardware, software,
network configuration, deployment procedures, and development guidelines
for the Quagga mussel robotic nest.

.. note::

   This project is under active development.
